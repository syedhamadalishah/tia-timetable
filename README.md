## 🚀 Features
- **Live Class Radar**: Real-time status badge and active session tracker with countdowns.
- **Weekly Schedule**: Day-by-day timetable view with subject, room, and teacher filters.
- **Teacher & Class Directory**: Comprehensive index of subjects, classrooms, and faculty.
- **Database Management**: Dynamic course and session configuration backed by SQLite.
- **Search Engine Optimization (SEO)**: Pre-configured JSON-LD Structured Data, OpenGraph tags, `robots.txt`, and `sitemap.xml` for Google Search indexing.
